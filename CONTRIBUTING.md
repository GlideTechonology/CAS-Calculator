## 🛠️ How to Contribute

1. **Discuss First:** For major features or architectural changes, please open an Issue to discuss before creating a PR.
2. **Coding Standards:**
   - Write clean, readable Kotlin code adhering to the official Kotlin style guide.
   - All code comments and documentation must be in **English**.
   - Ensure the app builds without errors via `./gradlew assembleDebug`.
3. **Pull Request Checklist:**
   - Keep pull requests focused on a single feature or bug fix.
   - Include a clear description of the problem and your solution.
   - Reference any relevant Issue numbers.
